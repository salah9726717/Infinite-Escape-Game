INFINITE ESCAPE V3 - how to play on Android
1. Unzip INFINITE_ESCAPE_V3.zip and save index.html on your phone (Files app).
2. Open it with Google Chrome (Files > index.html > Open with Chrome).
3. The game is a single self-contained file: no internet, server or account needed. Once the file is on the phone it runs offline.
4. Progress and sound preference are saved in the browser's LocalStorage. (Some browsers do not save progress for file:// pages; the game warns if so.)
Controls: LEFT / RIGHT / JUMP buttons. Keyboard: arrows/A/D to move, Up/W/Space to jump.
Test mode: open index.html#dev to unlock every level in Level Select.
Implemented: 1000 levels / 100 ranks, seeded levels with jump-reachability checks, 3 lives, timer, 7 environments, per-level stickman color, scary surprises (level 6+, non-lethal), Web Audio sfx + mute (saved), Level Complete / Failed cards, pause, level select, save/reset.
Untested: this build was syntax-checked only; it has NOT been played on a real Android device or tested at every screen size, and levels were not automatically playtested. Report anything that feels unfair.
